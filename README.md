# Portfolio Website

Personal portfolio of **Al Aqsa Reto Wijaya**, Full-Stack Developer based in Jakarta, Indonesia.

Project roadmap: [roadmap.sh/projects/portfolio-website](https://roadmap.sh/projects/portfolio-website)

## Overview

This project builds upon the foundational semantic structure from the Basic HTML Website project, turning it into a responsive, styled personal portfolio website using modern CSS techniques.

## Objectives & Features

- **Semantic HTML5 Structure:** Clean, accessible page architecture (`header`, `nav`, `main`, `section`, `article`, `footer`).
- **Responsive Layout:** Mobile-first responsive design utilizing modern CSS Flexbox and Grid layouts.
- **Consistent Design System:** Defined color palette, typography hierarchy, and spacing system.
- **Pages Included:**
  - `index.html` - Homepage / Hero & About section
  - `projects.html` - Showcase of projects and accomplishments
  - `articles.html` - Technical articles and blog posts
  - `contact.html` - Contact information & accessible inquiry form

## Tech Stack

- HTML5 (Semantic & Accessible)
- CSS3 (Flexbox, Grid, Custom Properties / CSS Variables)
